Como a análise funciona

A API soma pontos para sete sinais no endereço. Com 0 pontos, nenhuma regra local disparou. Com 1 ponto ou mais, a URL recebe um alerta de Suspeita forte. Isso é uma triagem por regras, não uma confirmação de phishing.

  • 3 pontos: endereço em IP; informações antes de @.
  • 2 pontos: domínio codificado com xn--; cinco ou mais partes no nome do site.
  • 1 ponto: URL com mais de 120 caracteres; palavras de acesso ou verificação; uso de HTTP.

Esses sinais não provam que um site é fraudulento. A classificação mostra apenas o que as regras locais encontraram.

A análise usa somente regras locais, não consulta bases de ameaças e não confirma se um site é seguro. A extensão Chrome/Edge utiliza esta mesma API.
